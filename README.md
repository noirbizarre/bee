## Installation

```bash
brew install noirbizarre/homebrew-tap/bee
```

```bash
paru -S bee-agent  # or your AUR helper of choice
```

Or download a binary for your platform from the
[latest release](https://github.com/noirbizarre/bee/releases/latest).

## Usage

```bash
bee --help
```
